# 第一阶段体验升级设计规格

## 目标

基于开源浪漫网站调研结果，增强当前网站的故事感、复访感和最终仪式感。第一阶段包含三个模块：回忆电影胶片、每日小羊礼物、最终分步告白仪式。

## 设计原则

- 不改变现有章节路由和页面切换机制。
- 不引入新依赖。
- 优先使用现有数据和组件。
- 动画保持温柔、克制、移动端友好。
- 新模块要服务叙事，不做无意义堆叠。

## 模块 1：回忆电影胶片

### 位置

回忆章节，现有 `memory-cinema-section` 附近。

### 体验

- 用电影胶片视觉展示几帧专属回忆。
- 每帧包含照片、标题、短句。
- 点击胶片卡片后展开背面文字。
- 视觉关键词：胶片孔、放映光、暗粉紫、金色帧线。

### 文案

标题：

```text
我们的回忆电影胶片
```

副标题：

```text
不是每一帧都轰轰烈烈，但每一帧里有你，就值得被我收藏很久。
```

### 数据

在组件内部定义 3 张胶片：

- 小羊宝宝这一帧
- 游戏里发光的小羊
- 想一直保存的瞬间

## 模块 2：每日小羊礼物

### 位置

加油章节，`SheepComfortPasture` 后面。

### 体验

- 初始显示礼物盒和说明。
- 点击后显示当天固定礼物。
- 礼物通过日期计算索引，同一天结果稳定。
- 包含礼物 emoji、标题、正文、落款。

### 文案

标题：

```text
今日小羊礼物
```

按钮：

```text
打开今日小羊礼物
```

礼物包括：抱抱券、夸夸券、晚安星星、安心糖、好运铃铛、想你便签。

## 模块 3：最终分步告白仪式

### 位置

替换/升级现有 `SheepConfessionRitual`。

### 体验

- 仪式分三步点亮。
- 每点击一步，显示一段文案并点亮一个光环。
- 第三步后出现最终完整告白。
- 保留小羊视觉主体，增强心形光环和阶梯式情绪。

### 步骤

1. 谢谢你出现。
2. 想认真陪你。
3. 小羊宝宝，我喜欢你。

### 最终文案

```text
小羊宝宝，你不是路过我的世界。你是我想认真守护很久很久的人。如果可以，我想把以后的温柔都慢慢给你。
```

## 测试标准

- 回忆章节可看到 `我们的回忆电影胶片`。
- 加油章节可看到 `今日小羊礼物` 和打开按钮。
- 最终章节可看到三步仪式按钮。
- `npm test -- --run` 通过。
- `npm run build` 通过。

## 自检

- 三个模块位置明确。
- 不影响章节入场特效。
- 不影响现有小羊模块。
- 不新增外部依赖。
