# 小羊主题三层设计规格

## 目标

在现有浪漫情书网站中加入与“小羊”昵称强绑定的专属设计，让她进入网站时能感受到被温柔守护、被认真偏爱的私人感。

## 设计方向

整体采用“梦境牧场 + 星光守护 + 告白仪式”的方向。小羊视觉不做儿童化卡通，而做成奶白、毛绒、柔光、星空、草地融合的精致手账感。

## 三层结构

### 1. 首页小羊彩蛋

位置：`home` 页面右下角。

行为：

- 小羊趴在云朵上轻微漂浮。
- 点击后出现提示气泡。
- 多次点击触发小星星、小爱心散开。
- 引导她去“加油”章节发现安心牧场。

核心文案：

```text
咩～小羊宝宝的安心牧场已经亮灯啦，去“加油”那一章看看吧。
```

### 2. 加油章节安心牧场

位置：`GaokaoCheer` 后、进入“机关”章节前。

名称：

```text
小羊宝宝的安心牧场
```

行为：

- 点击小羊：小羊跳一下并切换安慰文案。
- 点击星星：出现星星加油文案。
- 点击月亮：出现晚安文案。
- 点击“抱抱小羊”：柔光扩散并出现拥抱文案。

核心文案：

```text
这里不是催你一定要立刻变得很厉害。
这里只是想告诉你，小羊可以慢慢来。
累了就靠一靠，害怕了就听我说：你已经很棒了。
```

### 3. 最后一章小羊告白仪式

位置：最终章节靠后，`final-section` 之后、转盘等互动前。

名称：

```text
把小羊宝宝抱进心里
```

行为：

- 初始为一只发光小羊和心形星轨。
- 点击按钮后进入 activated 状态。
- 显示最终守护文案。
- 周围出现星星、云朵、爱心柔光。

核心文案：

```text
小羊宝宝，你不是路过我的世界。
你是我想认真守护很久很久的人。
```

## 技术设计

修改 `src/App.jsx`：

- 新增 `SheepHomeEasterEgg` 组件。
- 新增 `SheepComfortPasture` 组件。
- 新增 `SheepConfessionRitual` 组件。
- 在首页渲染小羊彩蛋。
- 在 `GaokaoCheer` 后渲染安心牧场。
- 在最终章节附近渲染告白仪式。

修改 `src/styles.css`：

- 新增小羊形象 CSS。
- 新增牧场、星空、草地、云朵、月亮、星星样式。
- 新增点击反馈和柔光动画。

修改 `src/App.test.jsx`：

- 验证首页出现小羊彩蛋入口。
- 验证加油章节出现安心牧场标题。
- 验证机关章节现有断言不受影响。

## 测试标准

- `npm test -- --run` 通过。
- `npm run build` 通过。
- 首页、加油章节、最终章节均能正常展示新增小羊设计。

## 自检

- 没有未定义占位项。
- 三个模块的插入位置明确。
- 不改变现有路由和章节切换逻辑。
- 不引入新依赖。
