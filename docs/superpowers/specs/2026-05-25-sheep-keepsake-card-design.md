# 小羊专属纪念卡设计规格

## 目标

新增一张适合截图保存的“小羊专属纪念卡”，强化网站的纪念属性。卡片不做复杂下载能力，优先保证视觉精致、移动端可截图、内容专属。

## 位置

放在最终章节中，`SheepConfessionRitual` 后、转盘等互动前。理由是最终章节情绪最完整，纪念卡适合作为告白后的可保存结果。

## 内容

卡片包含：

- 名称：`杨星冉宝宝`
- 标题：`小羊专属纪念卡`
- 日期：当前日期，使用中文格式
- 今日祝福：从固定文案中按日期稳定选择
- 小羊视觉：复用 CSS 小羊图形
- 签名：`From：一直认真喜欢你的人`
- 提示：`可以截图保存这一张小小的偏爱证明`

## 交互

- 初始展示卡片正面。
- 点击 `换一句今日祝福` 可切换祝福文案。
- 点击 `点亮纪念卡` 后卡片进入发光状态，出现星星/爱心柔光。

## 视觉

- 尺寸适合手机截图。
- 颜色：奶白、浅粉、星金、柔紫。
- 风格：纪念证书 + 手账卡片 + 小羊梦境。

## 技术要求

- 不引入新依赖。
- 在 `src/App.jsx` 新增 `SheepKeepsakeCard`。
- 在 `src/styles.css` 新增对应样式。
- 在最终章节可见性选择器里加入 `.sheep-keepsake-section`。
- 在测试中断言最终章节出现 `小羊专属纪念卡` 和 `可以截图保存这一张小小的偏爱证明`。

## 验证

- `npm test -- --run` 通过。
- `npm run build` 通过。

## 自检

- 不影响现有小羊告白仪式。
- 不影响章节切换和入场特效。
- 卡片内容专属且不模板化。
